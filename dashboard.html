    No browser activity yet. Install the APIShield browser extension to see live activity here.

    This section needs the free APIShield browser extension, because a webpage cannot see what other tabs are doing on its own. The extension only sends the current page's address and download names to this agent on your own computer (127.0.0.1) - never anywhere else. Classification is heuristic (pattern-based): APIShield looks for several risk indicators together and labels uncertain cases "Suspicious", not "Malicious" - it does not use a live threat-intelligence database, so treat SAFE as "no obvious red flags found", not a guarantee.

    Scan this computer

    The scan checks running programs, open connections, listening ports, startup entries, the hosts file and the firewall. It only reads. It never changes or stops anything.

    The agent listens only on this computer (127.0.0.1) and other websites are not allowed to read from it. Nothing is sent to any server. Website names come from reverse DNS lookups through your normal DNS. It cannot read the contents of HTTPS traffic, passwords or messages.
